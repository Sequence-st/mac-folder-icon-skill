# 맥 폴더 아이콘 만들기 (v0.2)

사진이나 캐릭터 그림 한 장으로 「파란 기본 폴더 → 그 아이 얼굴 폴더」를 만든다.
그림은 사용자가 이미 쓰는 생성 도구로 뽑고, 나머지(테두리·배경·크기·입히기)는 이 스킬의 스크립트가 한다.

`<SKILL>` = 이 SKILL.md가 있는 폴더. 경로는 전부 이 기준.

## 0. 처음 한 번

```bash
bash <SKILL>/scripts/setup.sh
```
마지막 줄 `PY=...`의 파이썬을 아래 단계에서 쓴다(Pillow·numpy만 필요, 없으면 알아서 개인 환경에 설치).
macOS가 아니면 여기서 멈추고 「맥 전용」이라고 알린다.

## 1. 받기 (질문은 최대 2개)

- **누구로?** 반려동물 사진 / 내 캐릭터 그림 / 말로 설명. 파일은 끌어다 놓으면 된다고 안내.
- **어디에 입힐까?** 폴더 이름이나 경로. 나중에 정해도 됨.
- 그림체는 묻지 않고 기본값(아주 단순하고 귀여운 2D 스티커풍)으로 간다. 사용자가 원하면 바꾼다.
- 작업 폴더 = `~/Pictures/folder-icons/<이름>/`. 원본은 여기에 `ref.<확장자>`로 복사. 결과물을 바탕화면에 흩지 않는다.

## 2. 주문서 쓰기

`references/prompt_recipes.md`에서 맞는 틀(A 내 캐릭터 · B 반려동물 · C 말로만)을 골라 **영어** 주문서를 `prompt.txt`로 저장한다.

- 반려동물이면 사진을 확대해서 **그 아이만의 표시 무늬 4~5개**와 눈 색을 먼저 적고, 생성 전에 한 줄로 확인받는다.
  예(치즈 태비 고양이): 「이마에 주황 줄무늬 세 줄, 양 볼에 가는 줄 두 개, 턱 밑은 하얀 털, 눈은 노란색 — 맞죠?」
  예(강아지): 「이마에서 코까지 하얀 줄, 귀는 보는 사람 기준 왼쪽만 갈색, 눈은 짙은 갈색 — 맞죠?」
- 사진·그림은 **1장만** 레퍼로 쓴다.

## 3. 그림 뽑기 — 경로는 이 순서로 자동 선택

자세한 방법·도구 이름표는 `references/image_routes.md`.

1. **코덱스에서 돌고 있으면** 코덱스 내장 이미지 생성으로 뽑는다(추가 연결 필요 없음).
2. **클로드 코드에 이미지 생성 MCP가 연결돼 있으면** 그걸로 뽑는다. 도구 목록에서 자동으로 찾는다.
   여러 개면 한 번만 물어보고 `"$PY" <SKILL>/scripts/route.py set mcp --tool <도구> --model <모델>`로 기억한다.
   다음부터는 `route.py get`으로 바로 쓴다.
3. **둘 다 없으면** 구글 플로우를 브라우저 자동화(Claude in Chrome 확장 또는 플레이라이트)로 쓴다. 사용자 구글 로그인이 필요하다. 플로우 화면이 바뀌면 자동 클릭이 깨질 수 있다고 미리 말한다.
4. **그것도 안 되면** `prompt.txt`와 사진을 주고, 사용자가 아무 앱(ChatGPT·Gemini 앱 등)에서 뽑은 그림을 작업 폴더에 넣게 한다. 그다음부터는 자동.

공통 규칙
- 유료 경로는 **생성 전에 비용을 알린다**(견적 도구가 있으면 먼저 조회). 기본 **1장 · 1K · 1:1**.
- 결과는 작업 폴더에 `raw_1.png`(다시 뽑으면 `raw_2.png`…)로 저장한다.
- 생성 도구는 호출 전에 스키마를 읽고, 모르는 인자·모델 이름을 지어내지 않는다.

## 4. 다듬기

```bash
"$PY" <SKILL>/scripts/make_icon.py ~/Pictures/folder-icons/<이름>/raw_1.png ~/Pictures/folder-icons/<이름> --name icon_1
```
테두리 수리(선이 정말 사라진 곳만. 연한 연필 선은 그대로 둠) → 흰 배경 지우기(가장자리 섞임까지 풀어서 밝은 띠 없음) → 가장 큰 덩어리만 남기기(구석 워터마크·잡티 제거) → 맥 기본 폴더 크기·위치 맞춤 → 외곽선 비침 검사(선 안쪽 2~6px가 반투명이면 바탕화면 색이 비쳐 희끗해 보임. 300px 넘으면 다시 잘라 선을 그 그림의 선 색으로 메우고, 더 나아질 때만 바꿈).
결과: `icon_1_512.png`(입힐 파일) · `icon_1_1024.png` · `icon_1_check.jpg`(확인판) · `icon_1_report.json`.

## 5. 검사 — 확인판을 직접 열어 눈으로 본다

`icon_1_check.jpg`를 이미지로 열어서 아래를 하나씩 본다. 글로만 「잘 됐어요」라고 하지 않는다.
- 어두운 배경에서 테두리가 한 바퀴 끊김 없이 이어지는가(3배 확대 6칸)
- 테두리 바깥에 하얀 띠가 없는가(`halo_px`가 0에 가까운가)
- 외곽선이 비치지 않는가(`see_through_px`가 300 아래인가. 확인판 둘째 줄에 고친 결과가 나온다)
- 가능하면 파란 바탕 위에도 올려 본다. 연한 연필 선 그림은 어두운 바탕보다 파란 바탕화면에서 비침이 잘 보인다
- 폴더 모양인가: 앞판은 반듯한 주머니, 뒤판 왼쪽 위에 탭, 뒤판 윗선은 일자
- 얼굴이 가운데에 있고 눈·코가 너무 작지 않은가
- 반려동물이면 2단계에서 확인한 무늬·눈 색이 맞는가(왼쪽/오른쪽 포함)
- 그림에 없어야 할 글자·별 표시·잡티가 남지 않았는가

통과하면 확인판과 `icon_1_512.png`를 사용자에게 보여 주고 고를 기회를 준다.

## 6. 고치기

- 마음에 안 들면 **원래 사진/캐릭터 + 고친 주문서로 처음부터 다시** 뽑는다. 생성된 그림을 다시 넣어 「여기만 고쳐」라고 시키면 얼굴·무늬가 점점 무너진다.
- 단, 사용자가 「이 그림에서 이것만 지워줘」처럼 편집을 직접 원하면 그 그림을 편집한다.
- 다시 뽑을 때도 매번 비용을 먼저 알린다. 애매하면 장수를 늘리기 전에 주문서부터 고친다(`prompt_recipes.md`의 「자주 생기는 문제」).

## 7. 폴더에 입히기

```bash
osascript -l JavaScript <SKILL>/scripts/icon.js set ~/Pictures/folder-icons/<이름>/icon_1_512.png "<폴더 경로>" ["<폴더 2>" ...]
osascript -l JavaScript <SKILL>/scripts/icon.js has "<폴더 경로>"        # yes 면 성공
```
- 파인더는 2~3초 뒤 알아서 새로 그린다. 옛 아이콘이 보이면 창을 닫았다 다시 연다.
- ⛔ 파인더 AppleScript `update` 명령을 부르지 않는다. 입힌 아이콘이 다시 빠질 수 있다.
- 바탕화면·문서 폴더를 처음 건드리면 맥이 접근 허용 창을 띄울 수 있다. **사용자가 직접 「허용」을 누르게** 안내한다.
- 확인이 필요하면 `icon.js readback "<폴더>" check.png`로 맥이 실제로 보여 주는 그림을 저장해 비교한다.

## 8. (선택) 새 폴더 자동 입히기

사용자가 원할 때만.
```bash
bash <SKILL>/scripts/auto/install_auto.sh ~/Pictures/folder-icons/<이름>/icon_1_512.png      # 기본: 바탕화면
bash <SKILL>/scripts/auto/uninstall_auto.sh                                                  # 끄기
```
- 켤 때 이미 있던 폴더는 기억만 하고 안 바꾼다. 그 뒤에 새로 만든 폴더만 바뀐다.
- 「무제 폴더」는 이름을 다 정한 뒤에 바뀐다(이름 입력 중에 바꾸면 파란색으로 깜빡임).
- 처음 한 번 「osascript이(가) 데스크탑 폴더에 접근하려고 합니다」 창이 뜨면 사용자가 「허용」을 누른다.

## 9. 되돌리기

```bash
osascript -l JavaScript <SKILL>/scripts/icon.js remove "<폴더 경로>"
```
또는 폴더 선택 → ⌘I(정보 가져오기) → 왼쪽 위 작은 아이콘 클릭 → delete.

## 지킬 것

- **남의 캐릭터·작품을 레퍼로 쓰지 않는다.** 유명 캐릭터 이름을 주문서에 쓰지 않고, 남의 그림을 생성에 붙이지 않는다. 「○○ 같은 그림체로」라고 하면 선 굵기·눈 모양·색감 같은 특징을 말로 풀어 쓴다. 레퍼는 사용자 본인 반려동물 사진이나 본인이 권리를 가진 캐릭터만.
- 유료 생성은 매번 비용을 먼저 알리고 1장씩.
- 사진은 사용자가 고른 생성 서비스로만 보낸다. 다른 곳에 올리지 않는다.
- iCloud·드롭박스 같은 동기화 폴더에 입히면 숨은 `Icon` 파일도 같이 동기화된다는 걸 알려 준다.
- 문제가 생기면 `references/troubleshooting.md`.
