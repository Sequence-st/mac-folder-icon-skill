# 맥 폴더 아이콘 스킬 v0.2

반려동물 사진이나 내 캐릭터 그림 한 장으로, 맥의 파란 폴더를 그 아이 얼굴 폴더로 바꿔 줘요.
원하면 바탕화면에 **새 폴더를 만들 때마다 자동으로** 그 아이콘이 입혀지게도 해 줘요.

## 필요한 것
- 맥(macOS)
- 클로드 코드(클로드 데스크톱 앱의 Code 포함) 또는 코덱스
- 그림 뽑을 곳 하나. 아래 중 있는 걸 알아서 골라요.
  1. 코덱스를 쓰면 코덱스가 직접 그려요.
  2. 클로드 코드에 이미지 생성 서비스(매그니픽·힉스필드·폴로·빠나나·오픈아트·클링 등)가 연결돼 있으면 그걸로 그려요.
  3. 둘 다 없으면 구글 플로우를 브라우저로 대신 눌러서 그려요(구글 로그인 필요).
  4. 그것도 어려우면 주문서 문장을 드려요. ChatGPT나 Gemini 앱에서 직접 뽑아 폴더에 넣으면 나머지는 자동이에요.
- 그림 뽑는 비용은 쓰는 서비스 요금이에요. 뽑기 전에 꼭 먼저 알려 드려요.

## 설치
- **링크로(추천)**: 클로드 코드나 코덱스에 이 문장을 붙여 넣어요.
  `https://github.com/Sequence-st/mac-folder-icon-skill 이 스킬 설치해줘`
- **zip으로**: zip을 다운로드 폴더에 둔 채, 클로드나 코덱스에게 「다운로드 폴더에 받은 맥 폴더 아이콘 스킬 zip 설치해줘」라고 말해요.
- **직접 하기**: zip을 풀고 터미널에서 `bash mac-folder-icon/install.sh`
  - 코덱스용 자리 `~/.agents/skills/mac-folder-icon`, 클로드 코드용 자리 `~/.claude/skills/mac-folder-icon`에 같이 들어가요.
  - 처음 한 번 그림 도구(Pillow·numpy)를 설치해요(1분 안팎).

## 이렇게 말하면 돼요
- 「우리 고양이 사진으로 폴더 아이콘 만들어줘」(사진을 끌어다 놓고)
- 「내 캐릭터 그림으로 맥 폴더 만들어서 '작업' 폴더에 입혀줘」
- 「눈을 더 크게」「무늬 위치가 반대야」처럼 보고 말로 고쳐요
- 「바탕화면에 새 폴더 만들면 자동으로 이 아이콘 되게 해줘」
- 「원래 파란 폴더로 돌려줘」 · 「자동으로 바뀌는 거 꺼줘」

## 알아 두면 좋은 것
- 만든 파일은 `사진(Pictures) > folder-icons > 이름` 폴더에 모여요.
- 처음 바탕화면 폴더를 바꿀 때 맥이 「접근 허용」 창을 띄울 수 있어요. 「허용」을 눌러 주세요.
- 아이콘은 2~3초 뒤에 바뀌어 보여요. 그대로면 창을 닫았다 열어요.
- 맥 전체의 기본 폴더 모양은 바꿀 수 없어요(맥 보호 영역). 대신 자주 쓰는 폴더와 새 폴더에 입혀요.
- 사진은 내가 고른 그림 서비스로만 보내요.
- 다른 사람의 캐릭터나 그림으로는 만들지 않아요. 내 반려동물, 내가 권리를 가진 캐릭터로 만들어요.

## 들어 있는 것
- `SKILL.md` 클로드·코덱스가 읽는 순서
- `references/` 주문서 틀(캐릭터·반려동물) · 그림 뽑는 곳별 방법 · 문제 해결
- `scripts/` 다듬기(테두리 수리·배경 지우기·폴더 크기 맞춤·확인판) · 폴더에 입히기·되돌리기 · 새 폴더 자동 · 설치 확인
