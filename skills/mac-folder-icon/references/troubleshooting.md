# 문제 해결

## 입혔는데 아이콘이 안 바뀌어 보여요
- 파인더가 다시 그리는 데 2~3초 걸린다. 기다렸다가도 그대로면 그 폴더가 보이는 창을 닫았다 다시 연다.
- `osascript -l JavaScript <SKILL>/scripts/icon.js has "<폴더>"` 가 `yes`면 아이콘은 들어가 있다(폴더 안 숨은 파일 `Icon` + 줄바꿈 문자).
- ⛔ AppleScript `tell application "Finder" to update ...` 는 쓰지 않는다. 입힌 직후 부르면 아이콘이 통째로 빠지는 일이 있다.

## 아이콘이 금방 다시 파란 폴더로 돌아가요
- `icon.js set` 은 입힌 뒤 확인하고 최대 3번 다시 입힌다. 그래도 빠지면 그 폴더가 동기화 폴더(iCloud·드롭박스 등)인지 본다. 동기화 프로그램이 숨은 `Icon` 파일을 다시 쓰는 경우가 있다.

## 「osascript이(가) … 폴더에 접근하려고 합니다」 창이 떠요
- 맥 보안 창이다. 사용자가 직접 「허용」을 누른다(자동으로 누르지 않는다).
- 「허용 안 함」을 눌렀으면: 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더(또는 전체 디스크 접근 권한)에서 해당 항목을 켠다.
- 자동 입히기(LaunchAgent)는 이 창이 떠 있는 동안 멈춰 있다가, 허용하면 이어서 돈다.

## 새 폴더 자동 입히기가 안 돼요
- 상태 보기: `launchctl print gui/$(id -u)/com.<사용자이름>.mac-folder-icon | grep state`
- 기록: `~/.config/mac-folder-icon/auto/auto.log`
- 이미 있던 폴더는 원래 안 바꾼다. 켠 뒤에 **새로 만든** 폴더만 바뀐다.
- 「무제 폴더」는 이름을 다 정한 뒤(최대 20초 기다림) 바뀐다. 파인더가 만든 이름은 한글이 풀어쓴 형태(NFD)라 스크립트가 합쳐서 비교한다.
- 끄기: `bash <SKILL>/scripts/auto/uninstall_auto.sh` (설정까지 지우려면 `--purge`).

## 어두운 배경에서 테두리 바깥에 하얀 띠가 보여요
- `make_icon.py`는 가장자리의 흰색 섞임을 풀어서 띠를 없앤다. 확인판의 `light halo pixels` 가 0이 아니면 그 그림의 테두리가 아주 연하거나 바탕이 순백이 아니었던 것. 주문서 블록 W(`pure flat white #FFFFFF`)로 다시 뽑는다.

## 파란 바탕화면에서 테두리가 희끗희끗해요
- 연한 연필 선을 배경 지우기가 「흰 바탕이 섞인 색」으로 보고 반투명하게 만든 것. 선 사이로 바탕화면 색이 비친다. 어두운 배경 확인판에서는 잘 안 보인다.
- `make_icon.py`가 선 안쪽 2~6px의 반투명 픽셀을 센다(`see_through_px`). 300이 넘으면 가장자리 2~3px만 풀어서 다시 자르고, 바깥 선 띠를 그 그림의 선 색으로 메운다. 비침이 1/4 아래로 줄고, 테두리가 15% 넘게 거칠어지지 않고, 하얀 띠가 새로 생기지 않을 때만 바꾼다(확인판 둘째 줄).
- 고친 게 마음에 안 들면 `--no-edge-fix` 로 끄고 다시 다듬는다.

## 폴더 옆면이 깎여 보여요
- 생성 그림의 바깥 선이 정말 사라져서(선 자리가 안쪽 색과 같음) 배경이 파고든 것. `make_icon.py`가 그런 곳만 찾아, 양옆의 실제 선에서 잰 색·굵기로 다시 그어 닫는다(확인판 첫 줄에 고친 개수).
- 연하거나 거친 연필 선은 끊긴 게 아니라서 건드리지 않는다(예전 판은 이걸 끊김으로 보고 회색 띠를 덧그렸다).
- 아주 길게 끊겼으면(확인판에 「not repaired」) 그 그림은 버리고 다시 뽑는 게 깔끔하다.

## 구석의 별·로고·잡티가 남았어요
- 그림 본체와 떨어진 조각은 자동으로 지운다. 본체에 붙어 있으면 안 지워진다 → 주문서 W 블록으로 「흰 여백」을 충분히 두고 다시 뽑는다.
- 그림이 일부러 여러 조각(떨어진 반짝이 등)이면 `--keep-all` 로 다듬는다.

## git 저장소 안 폴더에 입혔더니 `Icon` 파일이 변경으로 잡혀요
- `.gitignore`에 줄바꿈 문자를 대괄호로 넣은 줄을 추가한다(그냥 `Icon\r` 로 쓰면 git이 줄 끝으로 보고 지운다).
```bash
printf 'Icon[\r]\n' >> .gitignore
```

## 원래대로 돌리고 싶어요
- 폴더 하나: `osascript -l JavaScript <SKILL>/scripts/icon.js remove "<폴더>"`
- 손으로: 폴더 선택 → ⌘I → 왼쪽 위 작은 아이콘 클릭 → delete
- 자동 입히기 끄기: `bash <SKILL>/scripts/auto/uninstall_auto.sh --purge`

## 맥 전체의 기본 폴더 모양을 바꿀 수 있나요?
- 안 된다. 기본 폴더 그림은 시스템 보호(SIP) 영역이라 바꾸지 않는다. 대신 자주 쓰는 폴더에 입히고, 새 폴더 자동 입히기를 켠다.

## 윈도우: 입혔는데 노란 폴더 그대로예요
- `win_icon.ps1 has "<폴더>"` 가 `yes`면 아이콘은 들어가 있다(폴더 안 숨은 `folder-icon.ico` + `desktop.ini`).
- 탐색기에서 F5. 그래도 그대로면 탐색기 창을 닫았다 연다. 아이콘 저장소가 오래된 그림을 들고 있으면 `ie4uinit.exe -show` 를 한 번 실행한다.
- `.ico`가 아니라 PNG를 주면 거절한다. `make_icon.py`가 만든 `icon_1.ico`를 쓴다.
- 「실행할 수 없습니다(스크립트 실행 정책)」가 뜨면 명령에 `-ExecutionPolicy Bypass`가 빠진 것. SKILL.md의 명령 그대로 쓴다(설정을 바꾸지 않는다).

## 윈도우: 문서·바탕화면 폴더 이름이 영어로 바뀌었어요
- 원래 `desktop.ini`가 있는 폴더는 아이콘 줄만 더하고, 원래 아이콘 줄은 `; mac-folder-icon old:` 로 적어 둔다. `win_icon.ps1 remove` 를 하면 원래 내용 그대로 돌아온다.

## 윈도우: 파이썬이 없대요
- python.org에서 파이썬 3을 설치한다. 설치 첫 화면의 「Add python.exe to PATH」를 체크한다. 마이크로소프트 스토어로 열리는 `python`은 가짜 바로가기라 쓰지 않는다.
